**[GitHub Copilot app][about-copilot-app]** は、エージェント主導の開発に使用するデスクトップアプリケーションです。GitHub Copilot CLI を基盤とし、GitHub とネイティブに統合されているため、リポジトリ、ブランチ、CI パイプラインをすぐに利用できます。自分ですべての作業を行うのではなく、複数のエージェントを個別の分離されたワークスペースで並行してガイドし、繰り返し作業を自動化するワークフロー向けに設計されています。Node.js のインストールとプロジェクトの準備ができたので、次はアプリをインストールしてリポジトリを接続します。

このレッスンでは、次のことを行います。

- GitHub Copilot app をインストールしてサインインします。
- GitHub リポジトリからプロジェクトをアプリに追加します。
- テンプレートで準備されたバックログなど、ワークスペースの構成を確認します。
- アプリについて知るために、簡単なチャットを試します。

## シナリオ

チームは、増え続けるバックログに取り組むために AI エージェントを導入しています。Copilot app では、issue の選択、エージェントの実行、変更のレビュー、プルリクエストのマージを一か所から指示できます。このレッスンでは、アプリをインストールして接続し、プロジェクトについての会話を始められるようにします。

> [!NOTE]
> 対象となる Copilot プランが必要です。Copilot Free、Copilot Student、または有料プラン (Pro、Pro+、Business、Enterprise) を利用してください。Copilot Business または Copilot Enterprise では、管理者が **GitHub Copilot app** ポリシーを有効にしている必要があります。

## GitHub Copilot app をインストールして構成する

GitHub Copilot app を使うには、まずインストールします。Windows、macOS、Linux 向けのバージョンが用意されています。アプリをインストールして認証し、Tailspin Toys リポジトリを追加しましょう。

1. ブラウザーで [GitHub Copilot app のランディングページ][download-app]を開きます。
2. 使用しているプラットフォーム向けのアプリをダウンロードし、ランディングページの手順に従ってインストールします。
3. インストール後、アプリを開きます。
4. **Sign in to GitHub** を選択し、画面の指示に従って認証します。データ所在地を設定した GitHub Enterprise Cloud を使っている場合は、**Use GitHub Enterprise** を選択し、`*.ghe.com` のホスト名を入力します。GitHub Enterprise Server はサポートされていません。
5. オンボーディング中にリポジトリを選択する画面が表示されたら、テンプレートから作成した Tailspin Toys リポジトリを選択します。リポジトリ選択をスキップし、後からプロジェクトを追加することもできます。
6. テーマの選択を求められたら選択し、オンボーディングを完了します。
7. サイドバーの **Sessions** の下にリポジトリが表示されているか確認します。すでに表示されている場合は、再度追加する必要はありません。
8. リポジトリがまだ接続されていない場合は、**Sessions** の横にある **+** を選択して新しいセッションを作成し、**Add GitHub repository** を選択します。前提条件のレッスンで控えた所有者名とリポジトリ名を入力します。
9. サイドバーにリポジトリが表示されていることを確認します。このワークショップで使うレイアウトでは、`tailspin-toys` などのリポジトリフォルダーが **Sessions** の下にグループ化され、その中に個々のセッションが表示されます。

## ワークスペースを確認する

プロジェクトを接続したら、アプリの使い方を確認しましょう。サイドバーには次の領域があります。

- **New** — ここから Copilot との新しいチャットセッションを開始できます。
- **Pull requests** — アプリの GitHub ネイティブ統合を通じてプルリクエストを表示します。アプリを離れずに、プルリクエストの参照や絞り込み、CI 状態の確認、レビューを行えます。
- **Issues** — GitHub issue を表示します。issue の参照や絞り込み、issue からのセッション開始を行えます。
- **Automations** — スケジュールまたはオンデマンドで実行する保存済みエージェントタスクです。To Do リストの管理、定期的なプロジェクト保守、その他の面倒な作業の委任に役立ちます。振り返りでは次のステップとして紹介しますが、追加の演習はありません。
- **Customize** — MCP サーバー、プラグイン、スキルなどのコンポーネントを追加して、Copilot app に機能を加えます。Playwright MCP の設定で使用します。
- **Chats** — ブランチや独自のワークスペースを必要としない、質問やブレインストーミングのための軽量な会話です。最初のチャットを開始すると表示されます。表示されていない場合は、**Sessions** の横にある **+** を選択してチャットを開始します。
- **Sessions** — リポジトリフォルダーと、その中のエージェントセッションをまとめます。リポジトリ名 (`tailspin-toys` など) を選択してリポジトリビューを開くか、その下にあるセッションを選択して会話に戻ります。セッションごとに分離されたワークスペースで動作するため、複数のセッションを同時に実行しても変更が競合しません。星評価を追加するレッスンで最初のセッションを開始します。

ワークショップを進めながら、ワークスペースの使い方を確認していきます。

> [!TIP]
> 迷ったときは Copilot に質問しましょう。操作方法が分からない場合や、何かを実行できるか確認したい場合は、Copilot に尋ねると案内してくれます。

### 用意されたバックログを確認する

バックログのないプロジェクトはほとんどありません。Tailspin Toys も同じです。テンプレートからリポジトリを作成したときに用意されたバックログを確認しましょう。

1. サイドバーの **Sessions** で、個別のセッションではなく Tailspin Toys のリポジトリフォルダーを選択します。リポジトリの上部ナビゲーションで **Issues** を選びます。
2. issue 番号を決めつけず、次のタイトルを探します。

   - Allow users to filter games by category and publisher
   - Update our repository coding standards

3. issue を選択して詳細を読みます。各 issue からエージェントセッションを開始できます。最初の小さな変更を完了した後、フィルタリング issue から作業を開始します。

> [!NOTE]
> **Issues** と **Pull requests** の一覧は自動的に絞り込まれ、Copilot app に追加したリポジトリの項目だけが表示されます。他のリポジトリの作業項目を確認するには、そのリポジトリもアプリに追加してください。

## クイックチャットを試す

アプリの使い方に慣れるには、アプリ自体について質問するのが効果的です。**クイックチャット**を使うと、ブランチや worktree を作成せずに質問したり、アイデアを検討したりできます。セッションが不要な簡単な質問に適しています。

1. サイドバーの **Chats** の横にある **+** を選択して新しいチャットを開きます。**Chats** がまだ表示されていない場合は、**Sessions** の横にある **+** を選択して最初のチャットを始めます。開始後に **Chats** が表示されます。
2. アプリのセッションの仕組みについて、次のように質問します。

   ```plaintext
   How does the GitHub Copilot app use worktrees?
   ```

3. 会話ビューで回答を読みます。各セッションが分離された独自の Git worktree で動作するため、複数のエージェントを並行して実行しても変更が競合しないことを確認します。いつでも会話を続けたり、新しいチャットを開始したりできます。

## まとめと次のステップ

GitHub Copilot app をインストールしてプロジェクトを接続し、ワークスペースを確認しました。次のことを学びました。

- アプリをインストールして GitHub にサインインする。
- GitHub リポジトリからプロジェクトを追加する。
- ワークスペースを確認し、**Issues** で用意されたバックログを見つける。
- クイックチャットで、その場限りの質問をする。
