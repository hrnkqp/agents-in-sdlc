前の数回の演習では、ユーザーエクスペリエンスの改善と機能追加を目的に、GitHub Copilot クラウドエージェントに 3 つのタスクを依頼しました。クラウドエージェントは非同期かつ自律的に動作しますが、タスクを監視することも重要です。

GitHub.com の[エージェントページ][agents-page]など、クラウドエージェントに割り当てたタスクを管理する方法はいくつかあります。このミッションコントロールでは、オープンなプルリクエスト (PR) があるすべてのエージェントタスクを確認できます。実行内容を調べたり、進行中のセッションをガイドしたりすることもできます。

このレッスンでは、次のことを行います。

- エージェントページでクラウドエージェントのタスクを監視します。
- 進行中のセッションをガイドして機能追加を依頼します。

## シナリオ

エージェントにハイコントラストモードを作成させた後、チームはライトモードも追加することにしました。サイトのスタイルと切り替え機能を更新しているため、同じ作業に含めるのが合理的です。エージェントをガイドし、ハイコントラストモードに加えてライトモードも追加します。

## Copilot クラウドエージェントのタスクを確認する

Copilot クラウドエージェントに割り当てられたタスクの現在の状況を確認しましょう。

1. [Copilot エージェントページ](https://github.com/copilot/agents)に移動します。
2. メインペインと左ペインの両方にタスク一覧が表示されます。Copilot に割り当てた次のタスクがあることを確認します。
    - コードベースのドキュメントの更新。
    - ゲーム変更用 API の生成。
    - Web サイトへのハイコントラストモードの追加。
3. 実行中のタスクを 1 つ選択し、Copilot が実行したタスクを確認します。次のような作業が表示されることがあります。
    - リポジトリからコードをチェックアウトする。
    - Copilot の作業環境を作成する。
    - MCP サーバーを設定する。
    - 割り当てられたタスクを完了するための手順を実行する。

> [!NOTE]
> 表示される手順は、Copilot の作業状況や実行方法によって異なります。

4. 右側に表示されるプルリクエスト (PR) ペインも確認します。PR と変更されたファイルを確認して、作業をさらに監視できます。

## クラウドエージェントをガイドする

実行中のタスクを確認できたので、ハイコントラストモードに取り組んでいる Copilot に、ライトモードの切り替えも追加するよう依頼します。

1. ハイコントラストモードのタスクに対応するセッションを選択します。正確なタイトルは Copilot が付けた名前や作業状況によって異なります。

    ![ミッションコントロールのアクセシビリティセッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、作業が始まったことを示すメッセージが表示されるまで、数分間セッションを確認します。
3. **Steer active session while Copilot is working** ダイアログに次のプロンプトを入力します。

    ```plaintext
    While we are working on a high contrast mode, let's also add a light mode. There should be a switch for this mode as well where users can select their desired display mode.
    ```

    ![エージェントページ上のクラウドエージェントタスク。Copilot 作業中のアクティブセッションをガイドするダイアログが強調表示されている](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトを受け取り、作業に含めたことを確認します。

## Copilot の作業を待つ

Copilot は更新されたタスクに取り組みます。メッセージを送信した時点で作業中だった手順が終わると、新しい依頼を作業に取り込みます。

今回も完了までに数分かかります。その間に、これまでに学んだことを振り返りましょう。

## まとめと次のステップ

GitHub Copilot クラウドエージェントのタスクを監視し、ガイドするための中心的な場所である Copilot エージェントページを確認しました。このミッションコントロールでは、実行中および完了したタスクを追跡し、作業内容をレビューして、進行中のタスクを変更できます。

このレッスンでは、次のことを行いました。

- ミッションコントロールとエージェントページを使って、クラウドエージェントのタスクを監視しました。
- 進行中のセッションをガイドし、機能追加を依頼しました。

Copilot がアクセシビリティ機能を完成させたら、次は Copilot が作成したプルリクエストを[反復して改善][next-lesson]します。
